How it works

01
PR opened on your repo
GitHub fires a pull_request.opened webhook to the deployed server. CodeSenseiAI responds 200 immediately.
02
Signature verified + diff fetched
HMAC-SHA256 validates the request. Octokit fetches all changed files and builds an exact line → diff position map.
03
Gemini 2.5 Flash analyzes the code
The diff with exact line numbers is sent to Gemini. It returns structured JSON — severity, category, explanation, and fix per issue.
04
Inline comments posted to the PR
Each comment lands on the exact problematic line with the current implementation shown and a suggested fix below it.
